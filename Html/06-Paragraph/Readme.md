# Paragraph
paragraph always starts from a new line.

```
<p>This is a paragraph.</p>
<p>This is another paragraph.</p>
```

# Horizontal Rule 
HR tags specifies the horizontal line or rule that diffrentiate the sections.

Separating sections: Creates a visual break between different topics or paragraphs.

```
<h1>This is heading 1</h1>
<p>This is some text.</p>
<hr>
<h2>This is heading 2</h2>
<p>This is some other text.</p>
<hr>
```
# Line break
It is used to end the line and start from the new line.
```
<p>This is<br>a paragraph<br>with line breaks.</p>
```

# Use of Pre tag
this tag is use to directly start new line and specific formatting without any tags.

```
<pre>
  My Bonnie lies over the ocean.

  My Bonnie lies over the sea.

  My Bonnie lies over the ocean.

  Oh, bring back my Bonnie to me.
</pre>
```
