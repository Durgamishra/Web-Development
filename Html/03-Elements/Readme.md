# Html elements
These are starts from the tags and contains elements content and closed by closing tags.

```
<h1>This is the example of an element.</h1>
```
# Nested elements
Inside an element there is another element 

Eg-:
```
<html>
    <body>
        <h1>The heading element is under the body element </h1>
    </body>
</html>
```

* Html tags are not case sensitive both <p> and </P> are same both small case and uppercase are same.
